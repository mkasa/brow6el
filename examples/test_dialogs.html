JavaScript Dialog Tests for brow6el

1. Alert Dialog

Tests the alert() function. Press Enter or any key to dismiss.

2. Confirm Dialog

Tests the confirm() function. Press 'y' for Yes or 'n' for No, or Enter for OK.

3. Prompt Dialog

Tests the prompt() function. Type text and press Enter to submit, or ESC to cancel.

4. Multiple Dialogs

Tests multiple dialogs in sequence.

5. Long Messages

Tests dialogs with long messages to verify truncation.

6. File Downloads

7. Bookmarks Test

Ctrl+D - Add current page to bookmarks
Ctrl+B - Open bookmarks view
Navigate with ↑/↓, press Enter to open, 'd' to delete, ESC to close

8. Console Test

Ctrl+K - Toggle JavaScript console
Type JavaScript and press Enter to execute

9. User Scripts Test

Ctrl+U - Open user scripts menu
Ctrl+Y - Toggle auto-inject on/off
Navigate with ↑/↓, press Enter to inject, ESC to close

Setup:
1. Scripts location: ~/.brow6el_userscripts/
2. Config file: ~/.brow6el_userscripts.conf
3. Auto-inject based on URL patterns
